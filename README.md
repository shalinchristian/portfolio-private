# Shalin Christian | Portfolio

Personal portfolio at [shalinchristian.me](https://shalinchristian.me), built with React (Create React App) and Tailwind CSS.

## Run locally

```bash
npm install
npm start      # http://localhost:3000
npm run build  # production build in build/
```

Profile content lives in `src/data/profile.js`; each page section is a component in `src/Components/`.
